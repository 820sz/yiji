# 忆记 v1.1.4

这一版修了你这一轮列的全部 8 条。

## 1. AI 发图还是"图不在了"——根因是我自己上一轮引入的

为了让"渲染"和"把历史图重发给模型"只认一种引用,我把**内置表情包也抄了一份到应用私有目录**,消息里记那个文件名。那份副本会被系统清掉、也可能写失败——一旦没了,那条消息就**永久**显示"图不在了",而同一张图明明躺在安装包里。

现在:
- 内置表情包一律用安装包内的引用,不落盘(它不可能丢);
- 你自己发的照片和自添加的表情包仍然落盘(它们没有别的来源);
- **老消息会自动把图找回来**——按文件名回查图库,你不用做任何事。

## 2. 滑动卡帧 + 发消息不自动滚到新楼层

- 卡帧:可选中那一层原本包在**整个消息列表外面**,它要给整个视口建选区基础设施,滚动时每帧都在参与命中测试和语义树构建。改成只包每条消息。
- 不自动滚:原来只在发送那一刻滚一次,而新消息是之后才进列表的,那一帧的滚动范围还是旧值——滚过去等于没动。现在改用滚动范围通知:**内容一变高就贴住底部**;你自己往上翻就停手,滑回底部再自动跟上。

## 3. 表情包添加功能

存储和匹配两层早就做好了,**缺的一直是入口**。现在表情包面板标题栏有「+」:

选图 → 裁成方形 → **手填一句描述**。

描述是必填的,因为 AI 就是靠这句话挑图(它从清单里抄一条,系统按描述精确定位)。没有描述,这张图永远进不了候选清单——你会以为加了却用不上。

## 4. 日历里的想法能删了

列表项右侧有删除按钮(长按也行),删前确认一次。之前确实一条路都没有,写错了只能去改文字、删不掉整条。

## 5. 周报/月报:流式思考 + 自己打字调整需求

- 原来思考分片被**直接丢掉了**(`if (chunk.isReasoning) continue;`),界面上只看得到正文在长。现在思考块单独显示、定高 170、区内滚动、生成完自动收起。
- 成稿区加了输入框:写完点生成,它会作为**单独一条消息**附在数据之后发给模型。混进数据里的话,模型分不清哪部分是事实、哪部分是指令。

## 6. 进度页:手动重置

「更多」里两项,各自的契约说得很清楚:

- **重置进度(保留任务)**:推进条归零、推进记录清空,**待办和完成标记都留着**;
- **重设任务(保留进度记录)**:待办和挂在上面的提醒清掉,**进度记录保留**——那是已经发生的推进历史,不该因为换清单就消失。

两个确认弹窗都先写清"会删什么、会留什么",只问"确定吗"等于让你赌。

## 7. 个人名片放大

头像 58 → 68,名字 21 → 23,内边距和签名一起放宽。加在留白和字号上,不是硬撑高度。

## 8. 退出动画 + 可自定义语录

- 在第一个页签按返回键,弹出一个道别卡片(淡入 + 轻微缩放),默认「今天辛苦啦~」;
- 「我的 → 退出语录」可以改成你想要的任何话;
- 在别的页签按返回是**先回第一个页签**,不会直接把应用关掉;
- 点空白处是「再待会儿」,不会误退出。

## 9. 日历底部:本月想法(默认折叠)+ 状态曲线

- **这月记的想法**默认收起,点标题展开——日历的主体是日期,一屏里先看到的应该是格子。
- **状态曲线**:纵轴固定 0/25/50/75/100%,横轴日期,范围可选近 7/14/30 天(默认 7)。
  - 没安排任务的那天**线会断开**,不画成 0%——"那天没安排"和"那天全没做"看起来一样的话,曲线会骗人。
  - 纵轴固定不缩放:缩放会把正常波动画成断崖。

## 关于测试

你质疑得对,而且我有具体的例子。上一轮那个下载 bug:我的测试用的是 **4KB 假数据**,而真实包是 62MB——假数据既小于拦截页的量级、又完全不像 APK,**真实路径上两个致命问题一个都测不到**。跑了几十条绿的看着很安全,实际什么都没保住。

这一版我按"测试要贴着真实形态"补:
- 表情包渲染:从**打包进去的那份索引**取真实描述,走完 指令→挑图→落库→解析→**真的画出来** 全链,断言不出现"图不在了";
- 老消息找回:断言取回的字节和安装包里那张**逐一相同**;
- 重置的两个契约各有测试盯着"不该删的那一半还在";
- 日历默认折叠、状态曲线范围,都直接断言。

全量:**顶层 262 条 + 数据层 78 条**全绿;`flutter analyze` 无问题。

## 另外:v1.1.3 的下载修复也在里面

内置更新改成**并发竞速 + 边收边写盘 + 5 分钟总预算**(照你另一个项目 AI上外语 的做法)。原来下载会把 62MB 全读进内存、串行试错、而且没有超时——那就是"停在 0%"的原因。
