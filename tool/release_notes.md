# 忆记 v0.8.0

这一版把你提的 8 项都做了。老库会自动升级到 schema v4,数据不丢。

## 任务

- **左滑 = 完成,右滑 = 删除。** 以前左滑是删除,和"完成"这个天天用的动作正好相反。
  删除会弹一条带「撤回」的提示——它现在藏在右滑,误触的代价得有兜底。
- **长按拖起来排序。** 点表头新增的「调整顺序」进入排序模式,之后**按住任意一条
  就能拖**,不用去够右边那个小把手。长按在其他时候仍然是进多选(两者都是长按,
  只能有一个生效,所以拖动收进了排序模式)。
- **能标「没做好」。** 点进任务,底部有「完成情况」:达到预期 / 没做好。
  标了之后列表上会出现「没做好」小标,周报的「不足」那一栏也读得到它。
  以前只有"做完/没做完"两种状态,但"做了、可是没做好"才是最该被看见的那种结果。

## 进度

- **AI 会主动问你「要不要补一个目标」。** 你读了一周的书、但进度里没有"读书"
  这一条时,同步完它会单独列出来问你要不要建。勾选后**自动建好目标,并把这次
  已经完成的数量一起记进去**——不用你再手动补一遍。
  多个没被追踪的事会一次列出来,可以多选。
- 建出来的目标**不填目标值**,就是一条推进条:你做这件事之前本来就没定过要做到多少。

## 日历

- **换掉了那个挤成一团的时刻选择器。** 系统的 24 小时钟面把 0 到 23 全画在一个
  圈上,数字互相压着、指针盖着数字,想点 8 点很容易点到 20 点。现在是自己写的
  两列滚轮(小时 / 分钟),滚到哪选到哪,不需要瞄准。
- 顺便接入了中文本地化,系统自带的那些按钮不再是英文。

## 聊天

- **图片终于显示成图片了**,不再是"图片 xxx.jpg"这样一行字。点一下能放大看。
- **表情包来了。** 移植了 dsh-meme 那套「大肥鱼」图库,**108 张**,按情绪分好类
  (开心 / 生气 / 无语 / 害羞 / 困惑 / 惊讶 / 困了 / 工作 / 日常)。两种情况:
  - AI 自己挑:它觉得该接梗、该庆祝、该安慰你的时候会发一张。**不是每句都发**,
    它只在你情绪到点的时候用。
  - 你自己挑:输入框左边新增了一个表情按钮,可以按分类翻着找。
  - 图库在安装包里,离线也能发,不需要联网也不占额外下载。
- **每个对话有自己的头像。** 点聊天页顶部那个头像就能换,不同对话可以是不同人设。
  侧边栏里每条对话也是"头像 + 标题"。
- **回答生成时不再整页抖。** 以前每收到一个字都会重建整页(头部、输入框、
  整个消息列表),那是"乱飘"的根因;现在只有正在长的那一条会重绘。

## 我的

- **身份卡片每一项都能点着改了**:点头像换头像、点名字改称呼、点签名改签名、
  右下角画笔换背景图。之前整张卡被一个"改签名"的点击区包住,头像的点按被它抢走,
  换背景只有一个小图标、很难找到。
- 卡片本身也重新排了一遍:名字和签名各带一个编辑提示,背景上压的那层暗罩保证
  白字在任何图上都读得清。

## 验证

- 顶层 **189** 条测试、数据层 **67** 条 SQL 测试全绿,`flutter analyze` 无问题。
- 新增的测试覆盖:左滑完成、右滑删除+撤回、拖动排序落库、标"没做好"、
  v3→v4 迁移、时刻选择器、图片渲染成图、表情包指令不被显示且图会发出来、
  每个对话独立头像、名片四个编辑入口。
- 为了让"拖动排序"这条真的有证据,测试里按住 700ms 再分段移动——
  拖动识别器要等长按超时才认,按太短就只是一次普通轻触。

## 顺带修掉的

- 测试用的内存存储漏拷了 `avatar` 字段,导致"每个对话独立头像"看起来永远是坏的。
- `_autoSyncProgress` 原本在"一条目标都没有"时直接返回——而那**正是最该问
  「要不要建第一条」的时刻**,等于让新用户永远看不到这个功能。
