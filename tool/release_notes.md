# 忆记 v0.9.0

这次修的是你截图里指出的问题。

## 更新

- **新增版本横幅**:一进「我的」页就能看到「可以更新到 x.x.x」,点一下直接
  下载安装。以前只有"检查更新"那一行的小字副标题,字又小又混在一排设置项里,
  根本注意不到。
- **公告重新排版**:改成"一句话摘要 + 最多 5 条要点",并且**优先保留修 bug 的条目**。
  以前是把发布原文直接贴进来,满屏 `##`、`**`、`-`,一次十几条,抓不到重点。
- 点横幅和点「检查更新」现在是同一条路,不再有两份实现。

## AI 进度面板

- **修掉了顶部被状态栏遮住**的问题。根因是弹层用了"SafeArea + 最小高度 Column",
  条目一多整个面板就长过屏幕,标题被顶到时间和信号底下、底部按钮被推出屏幕。
  现在给定高度 + 内部滚动,标题和按钮永远在看得见的位置。

## 聊天

- **发表情包时,AI 能看懂你发了什么**。以前消息里只记一个文件路径,AI 只看到
  `![图] asset:memes/...`,完全不知道那是张什么图——自然接不上梗、也不知道
  你可能想斗图。现在消息里会带上这张图的说明(比如"被摸头眯眼冒爱心,脸蛋害羞开心"),
  AI 据此判断你是想逗它还是只是收个尾。
- **输入框里显示缩略图**,不再是"图片 xxx.jpg"这种文字。选了图之后要能一眼
  确认选的是哪张,那正是你此刻唯一关心的事。

## 我的名片

- **头像和背景真的能调了**:选图之后进调整页,可以**双指缩放、拖动位置**,
  头像还能选形状(圆 / 圆角方 / 方)。以前只能"选一张",主体偏了就毫无办法。
- **能改名字了**:点名片上的名字就能改称呼(以前只有设置页里那个输入框)。
- 调整结果会渲染成图片存下来,所以名片、聊天气泡、侧边栏看到的是同一张图。

## 验证

`flutter analyze` 无问题;全量测试 **196 条全绿**。
