# 忆记 v1.1.5

这一版**专修聊天页瘫痪**。上一版我引入了一个灾难性的回归,四个症状全是我造成的。

## 根因:我用「返回键」的通道去做页签切换

上一版为了做"退出道别",我在**根路由**上包了一层 `PopScope(canPop: false)`。

而关闭聊天侧边栏走的是 `Navigator.maybePop()`——那个 pop 请求落在**根路由**上,被这层 PopScope 拦下并执行了「回第一个页签」。

于是连锁反应:

| 你看到的 | 实际发生的 |
|---|---|
| 连点切换对话切换不了,直接跳到「任务页」 | 抽屉**关不掉**,人还被顶到任务页 |
| 各种弹层点空白处关不掉 | 同样被这层拦下,先跳页 |

**修法:彻底不用返回通道做页签切换。**
- 根路由那层 `PopScope` 整个删掉,返回键恢复系统默认行为;
- 侧边栏关闭改用 `Scaffold.closeDrawer()`(抽屉本来就是 Scaffold 的状态,不该借导航通道去关);
- "退出道别"改成「我的 → 退出忆记」一个**显式入口**,不再绑在返回键上。

## 四个症状各自的根因

**1. 切换对话跳到任务页** —— 见上。

**2. 上下滑动"卡死划不动"** —— 一个**回弹锁**:

我把"要不要贴住底部"的判断写成了"看当前位置"。结果:你往上滑 → 被 `jumpTo` 拽回底部 → 位置又变成"在底部" → 状态被重置成"该跟底" → 下次继续拽。你每一次滑动都被拉回去。

现在**只有手指能改变跟不跟底**(用 `ScrollStartNotification.dragDetails` 判断);同时给内容变高的处理加了深度判断——它以前会收到**任何后代**滚动区的通知,思考块里滚一下都会把外层列表拽到底。

**3. 点「思考过程」乱串屏幕** —— 两个叠加:
- 展开用 `AnimatedSize` 驱动高度,动画每帧都在改列表的滚动范围,而贴底逻辑同一帧跟着跳一次——140ms 约 8 帧、8 次跳转;
- 内部滚动区用了 `reverse: true`,内容从底部开始排,展开瞬间那块文字像是"从下往上贴"再被外层拽一下。

现在去掉 `reverse`(改成流式追加时自己滚到底),并修好回弹锁——跳动的来源没了。

**诚实说明**:我没有找到"布局真的串进别的消息"的代码证据,判断为上面两项造成的视觉错乱。如果真机上仍是内容跑到别的气泡里,请说一声,我需要一次 `flutter run` 的日志才能继续定位。

**4. AI 又看不到表情包** —— 是我上一轮改出来的:

为了修"图不在了",我把内置表情包改成"只有安装包引用、没有字节"。而发给模型的那份**只认字节**——于是内置表情包一个字节都发不出去,AI 收到的是纯文字请求。

现在:**任何有引用、没字节的图片都读出来**,不再按来源分叉。

## 验证方式(红 → 绿 → 撤掉修复再变红)

这四条症状在代码里放了 5 条回归测试,其中前两条是**先看到红、再变绿**的:

```
切换对话:留在聊天页,不跳到任务页          ← 修前红,修后绿
点思考过程:展开收起,不改动整页布局        ← 修前红,修后绿
用户发的图会真的发给模型(多模态)          ← 撤掉修复立刻红(Actual: []),
                                          恢复后绿
发消息后消息进列表,而且列表不卡死
弹层点空白处能关掉,而且不会跳到别的页签
```

`flutter analyze` 无问题;**顶层 267 条 + 数据层 78 条**全绿。

v1.1.4 那一批功能(表情包添加、日历删想法、周月报流式思考与自定义要求、进度重置、名片放大、日历底部状态曲线)都还在,这一版只动聊天页那四个 bug。

## 我要说清楚的

上一版我在**没搞懂 pop 通道语义**的情况下,把返回拦截放在了最外层,一次性弄坏了侧边栏、四个弹层、以及聊天页的滑动。这一版的修法是**把那个通道还回去**,而不是在上面再叠一层补丁。
