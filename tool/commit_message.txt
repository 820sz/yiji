忆记 v0.5.0:修 AI 乱记与会话隔离、进度按周期统计

两个设计错误的修复:
- 消息按会话隔离。以前所有对话混在一条历史里,新对话能看到旧对话的全部内容,
  AI 因此会提起你没在这个对话里说过的事。v3 加 conversations 表 + conversation_id,
  老消息归进"以前的对话"会话,并加了会话侧边栏。
- 目标的当前值只统计本周期。以前是所有历史求和,"每周 N 次"累积满了就永远不动。
  同时 target 改成可空(没有目标值时是纯推进条),单位可留空。

其他:
- 图片/文件上传:pickFiles 全程 try/catch(之前异常静默冒泡,表现为点了没反应)
- 聊天流式输出不再整列重排(改用 builder + key),修掉抖动
- 打钩加"圆圈填满 + 勾弹出"动画
- 「我的」顶部改成用户身份卡片(背景图/头像/ID/签名)
- 日历:任务可设系统通知提醒;每天按完成度显示 勾/半勾/叉
- 「待办」改名「任务」;新建目标弹层改用 DraggableScrollableSheet
- 提示词:支持"做一次就算一个单位"(健身→力量训练 +1 次),同时不许编造数字
- 修 bootstrap 只读消息不读会话列表(重开 app 后历史像丢了)
- 修启动时不重排提醒(手机重启后提醒不再响)

构建:开启 core library desugaring(flutter_local_notifications 需要)

验证:flutter analyze 0 issue;flutter test 122 passed;tool/sqltest 65 passed
