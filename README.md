# 忆记

每天的待办、想法、进度推进条、周报月报,加一个配了自己 API key 的 AI 聊天窗口。

一个自用的安卓 app:把"原子笔记记待办 → 手写周总结 → 复制给 AI 聊"这条流程收进一个应用,
让周报和进度条从真实打卡数据里长出来,而不是靠回忆。界面按 vivo 原子笔记的待办页还原。

纯本地存储、无账号、无服务端;AI 走你自己填的 key(默认 DeepSeek)。

## 它做什么

| 页面 | 你能做什么 |
|---|---|
| **待办** | 打开就是今天;加一条或粘贴一整段(行首 `-` `1.` `☑` 自动剥掉);**点文字进编辑、点右边圆圈打钩**;左滑删;长按进多选(颜色/删除/排序);**未完成与已完成之间有一条分界线**;左右翻看历史某天;写当天想法 |
| **日历** | 月视图,有安排的日子打点、全做完的打勾;点某天从底部弹出当天待办,就地增删改、左滑删除;未来的日期可以提前安排 |
| **进度** | 进度推进条:每周/每月/自定义目标,带进度条与"还差多少";点 ✨ 让 AI 读近期已完成的待办,给出推进建议(带判断理由),你确认后计入;也能手动加/改/删。建目标支持**说一句人话让 AI 拆字段**,也能直接填 |
| **聊天** | 头像跟随你所配的模型(DeepSeek 就显示 DeepSeek);思考强度四档(可只对本次临时改)、思考过程可折叠回看、流式输出;**可传图片与文本文件**;「带上近期数据」可选 7/14/30 天或自选区间 |
| **我的** | AI 头像(跟随模型或自己传图)、思考强度默认值、API key 与模型、周报/月报、导出数据、开屏文案、深色模式、检查更新 |

开屏是一行文案渐显,默认「小习惯、大不同」,在「我的 → 开屏文案」里改。

## AI 怎么帮你推进进度

这是这个 app 里唯一"聪明"的地方,分工是刻意这样切的:

1. **AI 负责读懂**:`码字2k`、`码了2千字`、`写了3k字` 是同一件事,规则匹配做不到,模型能。
2. **你负责确认**:建议会连同判断理由一起列出来,你逐条勾选后才计入。
   进度条是你判断"我到底有没有在推进"的依据,被猜错的数字污染比多看一眼糟糕得多。
3. **没有数字就不算**:待办里没写具体数量的(比如「下午 健身」「读《人物》」),
   AI 会跳过而不是猜——提示词里专门强调了这一点,因为逼它每条都给数字,它会硬凑。
4. **手动始终可用**:AI 只是省事,不是唯一入口。已计入的条目可以删掉重来。

## 数据在哪

全部在手机本地的一个 SQLite 文件里(`yiji.db`),不联网也能记。

**只有三个动作会联网**:让 AI 同步进度、生成总结、在聊天页发送。这三次会把当次需要的数据
(进度同步只带所选区间内已完成的待办;总结带上这段时间的打卡记录和你写的想法;
聊天只带你选了「带上近期数据」时的记录)发给设置里填的那个 AI 接口。
另外「检查更新」会访问 GitHub 读 release 信息。
没有账号、没有云端、没有第三方统计。

## 安装

从 [Releases](https://github.com/820sz/yiji/releases) 下载最新 APK 装到手机
(vivo 等系统需要允许「安装未知来源应用」)。

装过之后 app 会自己检查更新:我的 → 检查更新。

## 开发

```sh
flutter analyze                  # 静态检查,必须 0 issue
flutter test                     # 界面 + 日期 + AI 客户端,共 101 个测试
flutter build apk --release      # 出安装包
flutter run                      # 连上手机/模拟器直接跑

# 生成桌面图标(改了设计才需要跑)
python tool/make_icons.py
```

数据层(真 SQLite)的测试在独立包里跑:

```sh
cd tool/sqltest
flutter test                     # 55 个测试
```

真实 API 测试(验证 AI 判断质量,需要 key):

```sh
$env:DEEPSEEK_API_KEY="sk-..."; flutter test test/ai_live_test.dart
```

没配 key 时这组自动跳过——**跳过不等于通过**,它只是说这次没验。

**数据层测试为什么要分两处跑**:桌面版 SQLite 会触发 Dart native assets 编译,而它在安卓
打包时会失败并中断构建。把这份依赖挪出 app 包,打包链才干净。详见
[PLAN.md](PLAN.md#为什么数据层测试在-toolsqltest-独立包)。

装到手机:`flutter build apk --release`,然后
`build/app/outputs/flutter-apk/app-release.apk` 传到手机点击安装
(vivo 需要允许「安装未知来源应用」)。

## 一些刻意的选择

- **报告不落库。** 周报是对打卡数据的投影,随时现算。原始记录永远在,AI 写砸了不会毁掉数据。
- **目标当前值也不落库。** 由进度条目求和得出,不会出现"总数和明细对不上"。
- **周从周一开始。** 与 xi283 原本"周日晚上写周总结"的习惯对齐。
- **AI 只出建议,你确认才计入进度。** 进度条是判断自己有没有推进的依据,不该被猜错的数字污染。
- **界面不放教学式说明。** 提示只留必要的短句,不解释自己的功能。
- **动效克制。** 打钩是一天几十次的动作,只给 140ms 反馈、不做入场表演;
  唯一超过 300ms 的是开屏文案的淡入,因为那是"读一句话"。
- **错误直说。** 401 就说 key 不对,402 就说余额不足,不做静默重试假装在思考。
